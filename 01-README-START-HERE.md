## One-line workflow

Dataset analysis → channel audit → deep research → vidIQ keyword scoring → 60-day plan → script (playbook rules, banned-word scan = 0) → user records voiceover in Cartesia and sends the SRT → measure the SRT (runtime, wpm, chapters) → divide into ≤10-second scenes → character sheets → generate clips in batches of 6 (real-footage styles, no audio, upscale to 1920×1080, names = scene times) → upload pack with real chapter times → edit + captions.
